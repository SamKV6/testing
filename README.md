## TC-01 · Корзина в шапке

**Модуль:** Шапка сайта (`#header`)
**Тип теста:** UI / E2E
**Приоритет:** High
**Ветка:** `feat/tc-01-cart`
**Файл:** `tests/all.spec.ts`

### Preconditions

- Сайт `https://vladivostok.e-sweets.ru/` доступен
- Браузер запущен в чистой сессии (без сохранённых cookie и localStorage) — корзина пуста
- В `playwright.config.ts` задан `baseURL: 'https://vladivostok.e-sweets.ru/'`
- Селекторы `#cart`, `.cart_count` присутствуют на главной странице (см. `page-objects/selectors.ts`)

### Test Case 1.1 — Иконка корзины видна, ведёт на `/cart/` и показывает числовой счётчик

| # | Действие | Ожидаемый результат |
|---|----------|---------------------|
| 1 | Открыть главную страницу: `await page.goto('/', { waitUntil: 'domcontentloaded' })` | Страница загружена, DOM готов |
| 2 | Найти ссылку корзины: `page.locator('#cart').first()` | Локатор найден в шапке сайта |
| 3 | Проверить видимость: `await expect(cartIcon).toBeVisible()` | Элемент `#cart` отображается |
| 4 | Проверить атрибут `href`: `await expect(cartIcon).toHaveAttribute('href', '/cart/')` | Ссылка ведёт на `/cart/` |
| 5 | Найти счётчик: `page.locator('.cart_count').first()` | Локатор найден внутри `#cart` |
| 6 | Проверить видимость: `await expect(counter).toBeVisible()` | Счётчик отображается |
| 7 | Проверить формат текста: `await expect(counter).toHaveText(/^\d+$/)` | Текст счётчика — число (`0` в пустой корзине) |

**Ожидаемый результат (итоговый):**
- Ссылка `#cart` видна в шапке
- `href` равен `/cart/`
- Счётчик `.cart_count` виден и содержит только цифры

### Test Case 3.1 — Случайные символы не дают результатов, неполное название находит товары

**Предусловия:** desktop Chromium, новая сессия, сайт доступен, на главной странице есть товары.

| # | Действие | Ожидаемый результат |
|---|----------|---------------------|
| 1 | Открыть главную страницу: `await page.goto('/', { waitUntil: 'domcontentloaded' })` | Страница загружена, DOM готов |
| 2 | Найти название первого товара: `page.locator(product.titleLink).first()` | Название товара отображается |
| 3 | Прочитать название через `innerText()` и выбрать слово длиной от 5 букв | Получено слово из названия существующего товара |
| 4 | Удалить последние 2 буквы слова: `word.slice(0, -2)` | Подготовлен запрос с неполным названием |
| 5 | Найти поле поиска: `page.locator(search.desktopContainer).locator(search.input)` | Поле поиска в шапке отображается |
| 6 | Ввести `zxqwv1234codex987654321` и нажать Enter | Открыта страница поиска с указанным запросом |
| 7 | Проверить видимость `search.emptyWrapper` и текст `search.emptyHeader` | Отображается сообщение «ничего не найдено» |
| 8 | Ввести подготовленную часть названия и нажать Enter | Открыта страница поиска по неполному названию |
| 9 | Проверить: `await expect(page.locator(search.emptyWrapper)).toBeHidden()` | Блок пустой выдачи не отображается |
| 10 | Найти товары: `page.locator(product.titleLink)` и проверить видимость первого | Найден хотя бы один товар |
| 11 | Проверить названия результатов через `expect.poll()` | Хотя бы одно название содержит введённый фрагмент без учёта регистра |

**Ожидаемый результат (итоговый):**
- Запрос из случайных символов показывает сообщение «ничего не найдено»
- Поиск по неполному названию возвращает товары
- Хотя бы один найденный товар содержит введённую часть названия без учёта регистра

**Постусловие:** открыта страница результатов поиска; корзина и данные товаров не изменены.
